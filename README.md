# 📘 Solución de Ecuación de Segundo Grado

Este proyecto tiene como objetivo implementar una solución completa para resolver ecuaciones de segundo grado, tanto con raíces reales como complejas. Incluye una interfaz gráfica de usuario (GUI), validaciones de datos y pruebas unitarias siguiendo la metodología **TDD (Desarrollo guiado por pruebas)**.

---

## 🚀 Procedimiento de Implementación

1. Cálculo de raíces reales  
2. Subtest del cálculo de las raíces reales  
3. Cálculo del cálculo de las raíces complejas  
4. Subtest de raíces complejas  
5. Validar tipo de datos de los parámetros  
6. Subtest de validación del tipo de datos  
7. Interfaz gráfica de usuario (GUI)  

---

## 🌿 Crear ramas para cada Feature

1. Crear una rama `Feature` por cada funcionalidad  
2. Aplicar TDD  
   - Diseñar los casos de prueba para el Feature  
   - Prueba que falla  
   - Implementación del Feature  
   - Prueba que pasa  
   - Refactorización  
3. Sincronizar la rama `Feature` con su repositorio remoto  
4. Merge de `main` con la rama `Feature`
